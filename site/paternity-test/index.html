    赛鸽亲子鉴定指南：原理、流程与血统认证¶

    核心结论：赛鸽亲子鉴定通过 DNA 亲权比对科学确认鸽子的血缘关系，是血统认证与育种管理的核心工具。它基于孟德尔遗传定律，利用多个 SNP 位点计算亲权指数与累计亲权概率，排除准确率可达 99.9% 以上，远超依赖足环与血统书的传统判断方式。

    在赛鸽交易与育种中，「血统」是价值的核心。然而，传统依赖足环与血统书的方式，难以杜绝造假与记录错乱。赛鸽亲子鉴定以基因证据取代主观判断，让血统真正可验证、可追溯。

    赛鸽亲子鉴定的科学原理¶

    赛鸽亲子鉴定基于孟德尔遗传定律——子代的一半基因来自父鸽、一半来自母鸽。实验室选取多个高度多态的 SNP 基因位点，比对子代与疑似亲本的等位基因，通过两种逻辑判定：

    1. 排除法：若疑似亲本不具备子代「必须继承」的等位基因，即可直接排除亲子关系
    2. 确认法：若基因型完全符合遗传规律，则计算亲权指数（PI）与累计亲权概率，达到阈值即确认

    三狮生物采用 58 个独家 SNP 位点（57 个 SNP 位点 + 性别位点），位点更多、多态性更高，结果精准可靠。

    技术原理深挖：SNP 位点与亲权指数¶

    赛鸽亲子鉴定的核心是多态性遗传标记的比对，常用的标记有两类：

    标记类型 中文全称 特点 适用场景
    STR 微卫星/短串联重复 多态性高，传统法医学常用 人类亲缘鉴定
    SNP 单核苷酸多态性 数量多、稳定、易标准化、可高通量 高通量个体识别与亲权判定

    亲权指数（Paternity Index，PI）的计算逻辑是：在「疑似亲本是真实亲本」与「随机个体是亲本」两种假设下，观测到当前基因型的概率之比。PI 值越大，支持亲缘关系的证据越强。将多个位点的 PI 连乘，得到累计亲权指数（CPI），再换算为累计亲权概率——达到 99.99% 以上即可确认亲子关系；反之，若某一位点不符合孟德尔遗传规律，即可做出「排除」结论。

    关于 SNP 位点为何能高精度识别个体，可参考赛鸽遗传学基础。

    赛鸽亲子鉴定的应用场景¶

    场景 价值
    血统认证 验证名鸽血统真伪，杜绝虚假血统书
    育种管理 确认配对繁殖结果，防止「串种」
    参赛验证 验证参赛鸽血统，保障赛事公平
    引种溯源 确认引进种鸽的血统归属
    谱系建立 为新鸽系建立可靠的谱系档案

    检测流程实操¶

    1. 咨询下单：确定鉴定对象（子代 + 疑似父鸽/母鸽）与项目
    2. 羽毛采样：子代与疑似亲本分别拔取 4–6 根胸腹部羽毛（务必带根部毛囊）
    3. 实验室鉴定：提取 DNA，完成 58 个 SNP 位点的亲权比对
    4. 出具报告：附累计亲权概率的鉴定结论，作为血统认证依据

    完整流程见赛鸽亲子鉴定服务页。采样规范可参考基因库采样送检流程或联系三狮生物技术团队。

    💡 提示：亲子鉴定建议在配对时即记录血统、留存样本，为日后血统追溯提供依据。单亲鉴定（仅提供一方亲本）也可进行，但双亲鉴定确认概率更高。

    与基因身份证、AB 鸽检测的关系¶

    三者共同构成赛鸽身份与血统管理的完整体系：

    • 基因身份证：为每羽赛鸽建立唯一基因档案（58 SNP 位点二代测序）
    • AB 鸽检测：识别同名顶替鸽，防作弊
    • 赛鸽亲子鉴定：确认鸽子之间的亲子关系

    配合性别鉴定与近亲系数检测，可形成从「身份—血缘—近交—性别」的完整血统档案，详见本库首页。

    核心要点¶

    1. 赛鸽亲子鉴定靠亲权比对——比较 SNP 位点判断亲子关系。
    2. 排除准确率高——分子检测的亲权判定排除准确率可达 99.9% 以上。
    3. 羽毛即可检测——无需采血，幼鸽即可进行。
    4. 三大应用——血统认证、育种管理、参赛资格验证。
    5. 与基因身份证互补——建档 + 亲缘共同管理血统。

    常见问题¶

    亲子鉴定需要什么样本？¶

    拔取 4–6 根带根部毛囊的胸腹部羽毛即可，无需采血，对鸽子几乎无伤害，幼鸽阶段即可采样检测。

    亲子鉴定需要父母双方都提供样本吗？¶

    提供父母双方样本时确认概率更高；仅提供单方也可进行单亲鉴定，但需评估位点覆盖度。详见赛鸽亲子鉴定服务流程。

    亲子鉴定准确率多高？¶

    基于 SNP 位点亲权比对，排除非亲本准确率可达 99.9% 以上，是可靠的亲缘判定方法。

    亲子鉴定和基因身份证有什么区别？¶

    基因身份证回答「这羽鸽是谁」，是为单羽鸽子建立唯一身份档案；亲子鉴定回答「这羽鸽的父母是谁」，是确认鸽子之间的亲缘关系。两者配合可实现血统的完整溯源。

    幼鸽能做亲子鉴定吗？¶

    可以。羽毛即可提取 DNA，幼鸽阶段即可鉴定，便于早期确认血统、规范育种。

    单亲（只知一方）能做亲子鉴定吗？¶

    可以。仅提供一方亲本也能进行单亲鉴定，但结论的可信度与位点覆盖度有关，建议尽量补齐双方样本。

    亲子鉴定多久出报告？¶

    自动化测序流程高效，具体周期以检测服务说明为准。
